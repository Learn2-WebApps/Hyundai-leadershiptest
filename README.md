# 현장 리더십 주행모드 테스트

나의 현장 리더십 유형은? — 현장 상황에서 내가 주로 사용하는 리더십 행동을 알아보는 진단 웹앱.

## 실행

```bash
npm install
npm run dev
```

`.env.local.example` 을 `.env.local` 로 복사해 값을 채운다.

| 환경변수 | 설명 |
| --- | --- |
| `ADMIN_PASSWORD` | 관리자 비밀번호. **서버에서만** 읽으며 클라이언트 번들에 포함되지 않는다. 값이 없으면 관리자 로그인이 전부 차단된다. |
| `ADMIN_SESSION_SECRET` | 관리자 세션 쿠키 서명용 시크릿. 배포 시 반드시 교체. |
| `FIREBASE_PROJECT_ID` / `FIREBASE_CLIENT_EMAIL` / `FIREBASE_PRIVATE_KEY` | Firestore 연결 정보. **비워두면 서버 메모리 저장소로 자동 폴백**하므로 프로토타입 단계에서는 그대로 두면 된다. |

## 구조

| 경로 | 역할 |
| --- | --- |
| `src/lib/characters.ts` | 캐릭터 4종 데이터와 이미지 매핑(이미지 경로는 여기 한 곳에서만 관리) |
| `src/lib/questions.ts` | 12문항·선택지·유형 코드. `optionId`/`text`/`typeCode` 는 항상 한 객체 |
| `src/lib/scoring.ts` | 서버 재검증 채점, 동점 판정, 표시 점수 |
| `src/lib/store.ts` | Firestore 어댑터 + 메모리 폴백(동일 인터페이스) |
| `src/lib/admin.ts` | 관리자 비밀번호 검증과 HttpOnly 세션 쿠키 |
| `src/components/TestFlow.tsx` | 학습자 흐름(입장 → 사전 예상 → 안내 → 12문항 → 동점 → 결과) |
| `src/components/ResultView.tsx` | 학습자·관리자 공용 결과 화면 + PNG 저장 전용 레이아웃 |
| `src/components/AdminPanel.tsx` | 관리자 로그인·세션 관리·참여자 목록·상세 결과 |
| `public/characters/` | 기존 캐릭터 이미지 4개(원본 파일명 유지) |

## 동작 규칙 요약

- 문항은 한 화면에 상황 1개와 선택지 4개를 두고, 각 문장 오른쪽의 라디오 두 칸(● 가깝다 / × 멀다)에서 하나씩 고른다. 같은 선택지를 양쪽에 고르면 기존 선택이 해제되고, 둘 다 골라야 다음으로 넘어간다. `이전` 으로 돌아가 응답을 수정할 수 있다.
- 점수: 가까운 행동 `+1`, 먼 행동 `-1`. 유형별 `mostCount` / `leastCount` / `netScore` / `displayScore(((net+12)/24)*100)` 를 저장한다. 학습자·관리자 화면에는 수치나 차트를 표시하지 않고 DB에만 기록한다.
- 대표 유형은 `netScore` 최고 유형. 동점이면 동점 결정 문항(“다른 사람에게 가장 자신 있게 전할 수 있는 팁은?”)을 표시하며, 그 선택은 대표 유형 결정에만 쓰고 점수에는 더하지 않는다.
- 서버는 클라이언트가 보낸 유형 코드·점수를 신뢰하지 않고 `optionId` 로 다시 채점하며, 존재하지 않는 문항/선택지, 중복 선택, 문항 수 오류를 모두 거부한다.
- 세션 코드는 숫자 4자리 **문자열**(`"0047"`)로 저장하고, 종료된 세션에는 신규 참여가 차단된다. 세션 삭제는 참여자 데이터까지 함께 지운다.
- 결과 이미지(PNG)에는 제목·이름·캐릭터 이미지·유형명·한 줄 설명·주행 강점·주행 경고등·브레이크 한마디·해석 안내(+동점 안내)만 담는다. 날짜, 차트, 예상/결과 비교, 버튼류는 제외. 파일명은 `현장 리더십 주행모드 테스트_이름.png`.
- CSV 다운로드/내보내기는 구현하지 않는다.
